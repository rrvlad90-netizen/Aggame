Quake engine games MAP file cross compatibility test v3
=======================================================

Info
====
A simple random experiment that once popped out of my head.
This started from Return to Castle Wolfenstein map file,
that was copied to the other games.
Some indirectly from another game after small adjustments.

Textures had to be changed or the levels would
be unrecognizable.
I've used GtkRadiant and NetRadiant or the game's custom editor.
These editors can slightly change the map file automatically.
Some entity names had to be changed, because it can be
different for every game.
Sometimes I removed entities, because I couldn't find
the equialent entity for the game.

Doom 3 and Quake 4 needed manual conversion, other games were mostly fine.
SWAT3 is not a Quake engine game. It was using the Quake engine, but was
replaced with a custom engine that works like the Quake engine.
