Quake 3 Head MD3 Generator

1. Исходная MD3

Выберите MD3, из которой нужно создать голову.

2. Поверхности головы

Модель не загружена.

3. Кадры результата

Для скрытой головы рекомендуется один кадр. Quake 3 всё равно будет прикреплять её к tag_head модели upper.

4. Масштаб и положение

Пресет «Спрятать голову» устанавливает Scale = 0.05. При необходимости дополнительно сместите её внутрь тела. Не устанавливайте Scale = 0: все вершины совпадут, и Quake 3 может некорректно обработать поверхность.
