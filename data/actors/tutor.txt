Для гоблина лучше сделать 2 PNG кадра размером под его canvas:

lua
canvas = {
    width = 64,
    height = 80
}
То есть картинки:

64x80
прозрачный фон
ноги примерно на нижней линии кадра
центр персонажа примерно по x = 32
Например положи файлы так:

text
assets/sprites/goblin/walk_01.png
assets/sprites/goblin/walk_02.png
Потом в data/actors/goblin.lua замени walk:

lua
walk = {
            loop = true,
            frameDuration = 0.12,
            frames = {
                {},
                {},
                {},
                {}
            }
        },
на:

lua
walk = {
            loop = true,
            frameDuration = 0.16,
            frames = {
                "assets/sprites/goblin/walk_01.png",
                "assets/sprites/goblin/walk_02.png"
            }
        },
Можно и так, если хочешь настраивать длительность каждого кадра отдельно:

lua
walk = {
            loop = true,
            frames = {
                {
                    image = "assets/sprites/goblin/walk_01.png",
                    duration = 0.16
                },
                {
                    image = "assets/sprites/goblin/walk_02.png",
                    duration = 0.16
                }
            }
        },
Для начала я бы сделал 2 кадра:

walk_01 — левая нога вперёд;
walk_02 — правая нога вперёд.

Пример actor config

lua
{
    id = "big_goblin",
    solid = true,

    health = 10,
    speed = 80
}
Или прямо в уровне:

lua
{
    id = "goblin",
    x = 620,
    y = 555,
    solid = true
}
Что получится:

player не проходит сквозь solid actor-а;
другие actor-ы тоже не проходят сквозь solid actor-а;
solid actor не проходит сквозь player;
обычные actor-ы без solid = true работают как раньше.
